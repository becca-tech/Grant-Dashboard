## Deploying Updates

1. Edit `index.html`
2. Commit and push to `main` branch
3. GitHub Pages rebuilds automatically (takes ~30 seconds)

## Setup (First Time)

1. Create a new GitHub repository named `suni-grant-dashboard`
2. Upload `index.html` and `README.md`
3. Go to **Settings → Pages**
4. Set Source to **Deploy from a branch → main → / (root)**
5. Save — your URL will be `https://YOUR-USERNAME.github.io/suni-grant-dashboard`

## Contents

Tracks 15 grants across 5 phases:
- **Act Now / Open** — Climate Resilient Neighborhoods, NEA Our Town, Arts in Society, CTC Community Forestry
- **Summer 2026** — Denver CREATES, EDI Mini Grants, Mile High Weaver Awards, Bloomberg (prep)
- **Fall 2026** — PSYAH (primary target), DCCC Discretionary, CSFS Urban & Community Forestry, History Colorado
- **Early 2027** — Bloomberg Asphalt Art, AARP Community Challenge, Project for Public Spaces
- **Rolling** — Various

*Maintained by SUNI Land Use Committee*
